## 维护与引用规则

- 每类信息只在上表对应文档维护。README 仅保留可直接使用的快速示例，完整步骤在专题中展开；专题不把同一问题转回 README。
- 引用具体规则或章节，不以“详见其他文档”代替本文应承担的说明。指南可以引用架构与规范，规范不反向要求读者返回指南完成阅读；不添加返回索引式的依赖链接。
- 前端负责输入、选择和请求时机；下载负责任务与资源生命周期；UI 负责外观、排列及动效。接口只维护 HTTP 契约，平台操作与变量填写位置归部署文档。
- 目录职责以架构文档为准，命令和配置以源码为事实依据。代码行为或契约变化同步所属专题；内部重构只修正必要引用。
- 新增文档前优先补充已有专题；移动内容时更新本地链接与章节锚点。根目录两种语言的 README 保持内容对应，语言切换链接不属于职责依赖。
- 普通修正无需建立长期计划；复杂方案完成后先更新现行专题，再记录验证结果并归档。
