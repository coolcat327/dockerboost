## 维护边界

- 根 README 负责使用与部署概览，AGENTS.md 负责仓库长期约束；本文维护导航，不复制正文。
- 开发文档回答“如何接入”，接口文档回答“对外约定是什么”，下载文档回答“本地任务如何运行与清理”，视觉规范回答“界面遵循什么规则”。
- 接口的参数、响应和 HTTP 缓存策略只在接口参考维护；前端触发请求的时机与共享策略归前端开发。
- 方案的状态与验证证据归 plans，参考来源与取舍归 research，现行规则归相应专题。源码参数、完整文件清单和测试用例以实现为准，不逐项抄录。
- 新增或移动文档时更新本索引及所有受影响引用；跨主题只链接所属文档，不复制同一规则。
