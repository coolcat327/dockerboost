## 维护方式

同一规则只在所属专题维护，其他文档使用链接。接口参数与 HTTP 缓存归接口契约，本地下载生命周期归下载机制，控件与动效归视觉规范，仓库约束归 AGENTS。

专题优先描述当前行为、关键约束、实现入口、修改方式和验证方法；具体参数与完整文件清单以源码为准。新增文档应先考虑补充现有专题，移动文档时更新所有引用。

只有跨次执行的工作或复杂方案需要计划。普通样式修正、清理和逐次测试结果记录在提交或 PR；完成计划时先更新现行专题，再归档。历史记录不作为当前规范。
