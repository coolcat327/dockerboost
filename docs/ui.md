# DockerBoost 视觉与交互规范

本文件记录页面长期采用的设计规则。新增页面和功能应先复用 `src/client/styles/` 的变量、结构与控件；设计与实现按 [协作流程](design-workflow.md) 执行；方案状态见 [文档索引](README.md)。

## 视觉基调

采用炭灰磨砂表面、灰银流幕和品牌蓝。灰阶负责空间、材质与层次；蓝色用于品牌、选中、焦点和主要操作。成功、失败、停止使用明确语义色。新增功能不建立独立配色主题。

- 所有颜色优先复用 `foundation.css` 的变量：页面 `--bg`、面板 `--surface` / `--surface-2`、输入与命令 `--inset`、文字 `--ink` / `--muted` / `--subtle`、边界 `--line` / `--control-line`、品牌 `--cyan` / `--blue`、状态 `--success` / `--danger`。
- 装饰光幕与纹理统一放在 `atmosphere.css`；光幕锚定 Hero，以向视口两侧和顶部延伸的大画幅保留右上方远处斜射的聚光感，随 Hero 自然滚动，向工具区渐隐；窄屏调整光束落点覆盖上方插画，不固定在视口。不向各标签增加持续背景动画。颗粒静态，亮部避开正文，工具区保持稳定深色。
- 沿用 Manrope、中文回退字体与 DM Mono。正文、标题、按钮使用公共字体；命令、版本和下载数据使用等宽字体。禁止以字体特效改变命令或实际任务数据。
- 复用现有标题层级、间距、圆角及公共按钮、命令块与表单。专属 CSS 只描述领域差异，限定在对应面板；共用表面和控件修改到公共规则。

## 动效规则

使用 CSS 动画与少量原生 JavaScript，无 GSAP 依赖。复杂动效需求须先确认现有方案无法满足，避免仅为装饰引入整个框架。

- 使用公共 `--motion-fast`、`--motion-normal` 和 `--ease-out` 统一交互节奏；入场短暂、层间延迟克制，背景低频缓动。具体时长与幅度以 CSS 和 `hero-intro.js` 为准，不在文档重复维护参数。
- 页面布局与控件初始化不等待动画；中心展示仅作可中断的视觉覆盖，其他文字动效不从完全透明开始。原插画始终留在布局中；中心归位使用不可交互的装饰副本，任何滚动、窗口宽度变化或用户操作立即结束入场，不以等待动画阻止操作。
- 移动端地址栏引起的视口高度变化不取消入场，视口宽度变化仍立即结束；后台首次加载等待页面可见后播放，带锚点或功能分享链接时跳过入场。
- 常规动效优先使用 transform / opacity；短暂的标题动效可使用小幅模糊清晰化，命令与任务数据不模糊。插画可小幅轻浮动，并随页面隐藏或 Hero 离屏暂停。标签底线共享；进度只向真实数据过渡，不伪造百分比或完成状态。复制成功使用短暂勾选与状态提示。
- 指针视差仅在桌面精细指针设备启用，插画偏移保持小幅；指针事件按帧合并，只在事件发生时请求帧。容器柔光保持低对比，不影响命令阅读。
- 页面隐藏或 Hero 离屏暂停流幕；尊重 `prefers-reduced-motion`，关闭装饰动画、位移、平滑滚动和过渡。装饰层不参与点击或可访问性树。无脚本时正文仍可见。
- 状态反馈沿用现有任务入口与保护规则。任何视觉调整不得改变后台写入、停止、保存与清理生命周期。

## 响应式布局标准

本节是新增页面与布局调整的统一设计标准。优先复用现有断点、控件与排列方式；确需改变时，同步修改本节与所属 CSS，并说明内容宽度或操作需求，不能只针对一张截图追加覆盖规则。

### 宽度依据与断点

页面外框、导航及 Hero 使用视口媒体查询；工具面板内的表单、分栏与任务表使用 `@container workspace`，以 `.tool-stage` 内容区域的可用宽度为准。容器宽度不包含外框留白和面板内边距，不能将 1100px 的浏览器窗口当作 1100px 的表单空间。分屏、侧栏或嵌入时使用同一规则，不通过设备类型或 JavaScript 判断布局。

| 对象 | 容器宽度条件 | 标准布局 |
| --- | --- | --- |
| 拉取与单个下载表单 | 小于 540px | 单列，按镜像源、镜像名、架构、操作顺序排列 |
| 拉取与单个下载表单 | 从 540px 到宽屏断点前 | 两列，架构与操作同行，避免按钮独占下一行 |
| 拉取与单个下载表单 | 从 1040px 起 | 字段与操作同排 |
| 批量配置与候选镜像 | 小于 760px | 上下排列，配置在前，候选镜像在后 |
| 批量配置与候选镜像 | 从 760px 起 | 两列等宽、等高，共享网格行对齐标题、输入提示与内容区 |
| 下载队列及同类任务表 | 从 800px 起 | 镜像名、架构、进度、操作四列，表头与任务行共享列宽 |
| 下载队列及同类任务表 | 800px 以下且大于 480px | 镜像名占首行；架构与操作同行；进度和错误信息独占下一行 |
| 下载队列及同类任务表 | 480px 及以下 | 镜像名、架构、进度、操作纵向排列；表头按名称、统一设置、批量操作纵向排列 |

这些断点按组件职责使用，不要求所有页面在同一个宽度同时换行。安装页等其他已有表单沿用所属样式；新增同类任务表使用上述队列规则。下载标题与模式切换在容器 640px 及以下上下排列，不能挤占标题宽度。页面外框继续沿用现有 820px、600px 视口断点，导航的更窄适配由公共样式维护。

### 表格、控件与信息层次

- 宽屏任务表使用一个描边表面和行分隔线，不给每行叠加独立卡片；缩窄时重排行内内容，保留任务、架构、进度和全部操作，不隐藏关键状态来换取空间。
- 表头使用 15px、700 字重和正文主色；任务名沿用等宽字体。宽屏队列列间距为 24px，任务进度单元格左右各保留 16px 内边距，状态、错误信息和进度组件在进度列内居中；镜像名表头及内容左对齐，其他表头文字、架构框与操作组在各自列内居中。架构列固定 132px，不随宽屏拉长；镜像名与进度列按 0.85 : 1.15 分配剩余空间，架构控件不能紧贴进度文字。480px 及以下表头架构框继续铺满可用宽度。
- 队列下拉框、文字按钮、图标按钮使用同一尺寸组：宽屏高度 36px，800px 以下高度 40px，圆角 8px。表头与任务行共用 200px 的居中双按钮操作区，两列等宽且不随操作文案或任务状态变化；主操作随状态切换下载、停止、重新下载或重新解析，次操作为移除，不预留额外重试槽位。表头主按钮空闲时显示「开始下载」，排队、下载、自动重试或停止清理期间显示「停止全部」并使用危险色；右侧为炭灰描边的「重新解析」，队列为空、有任务解析中或下载未清理完毕时禁用。下载与重新下载复用公共蓝色主按钮，停止复用危险色按钮，移除复用炭灰描边次按钮，悬停、禁用与焦点沿用公共规则。
- 窄屏操作不得依赖悬停才能发现；图标按钮具有可访问名称及完整操作说明。480px 及以下架构控件显示字段标签，操作组铺满可用宽度，控件本身允许收缩。
- 镜像名保持单行，最大展示长度为 42ch，并受单元格可用宽度限制；超出以省略号展示，保留完整文本与悬停提示。批量进度区从待下载起固定为 54px（两行各 24px、间隔 6px），各状态不改变队列行高；失败或等待重试时，将状态与错误详情合并为进度条上方单行，保留最后一次实际下载的进度条；超长详情省略并保留完整文本及悬停提示。其他错误信息允许换行，不省略诊断内容。命令块局部滚动或换行，禁止页面整体横向溢出。
- Compose 输入框与候选列表内容区统一固定为 300px 高，空列表、少量或大量镜像均不改变高度；宽屏两侧上下边界对齐，窄屏上下排列时保持相同内容区高度。输入框关闭手动缩放和自动折行，长行横向滚动，多行纵向滚动；候选项在固定区域内滚动，滚动条预留槽位以避免增减内容导致宽度跳动。提示、错误与输入内容分层。控件换行不能改变字段含义、用户选择、解析状态或下载生命周期，DOM 与键盘顺序保持可理解的一致性。

当前规则由 `src/client/styles/workspace.css` 和 `src/client/features/download/download.css` 实现；控件颜色、字体与动效继续遵循本文件其他章节，不建立独立响应式主题。

## 适配与验收

布局变更按以下矩阵检查；仅文档变更按 AGENTS.md 检查链接、引用和差异即可。

- **视口与容器**：至少检查 320px、390px、768px、1100px、1280px 视口；另检查受影响容器断点的前后 1px（例如 479/480/481、759/760/761、799/800/801）。明确记录使用视口宽度还是容器宽度，覆盖断点附近、分屏或嵌入情况。
- **内容与语言**：中文、英文；空列表、单项与多项；长镜像名、长错误和长命令；架构未选中与已选中。确认文本不撑宽页面，所有按钮均可到达。
- **状态与交互**：正常、悬停、键盘焦点、禁用、加载、进行中、成功、失败；检查统一设置、单项覆盖、后续入队及解析失败提醒在换行后仍有效。开启减少动态效果后控件立即可用。
- **记录实际验证**：保留宽屏与窄屏的截图或检查结果，注明已测尺寸、语言和状态，以及未执行的检查。浏览器尺寸或 iframe 预览只能作为布局验证，不能代替物理设备与真实触屏验收。

工具区四个标签页的标语统一使用公共面板标题样式与字号，保持单行；中英文文案优先精简，详细说明放在下方正文，320px 窄屏下不得截断或溢出。

检查正常、悬停、键盘焦点、禁用、加载、任务进行中、成功和失败状态。标签支持方向键与 Home/End，活动标签和面板通过 ARIA 关联，键盘焦点始终清晰。正文对比度目标至少 4.5:1，控件禁用态应与可操作态可区分。

代码验证要求见根目录 [AGENTS.md](../AGENTS.md)。性能目标是无动画引入的布局偏移、操作不等待动效、后台不持续渲染；不能以开发机表现替代实际移动设备验证。

## 工具区交互层次

工具区借鉴 React Bits SpotlightCard 的隔离柔光层，保持内容上方无可交互装饰。指针柔光仅用于精细指针设备；键盘聚焦控件时显示静态顶部柔光和品牌色边界，具体控件仍保留独立焦点环。触屏无需悬停即可辨认入口。主要按钮仅在可操作时响应悬停；禁用时不改变底色，不用装饰暗示可点击。光色、边界与操作色使用公共变量。

## 操作控件

下载使用蓝色渐变主按钮，分享与刷新使用炭灰描边次按钮；复制使用紧凑描边按钮。图标使用 CSS 遮罩，与文字颜色同步，独立于语言和任务状态的文本更新；停止状态切换方形图标及危险色，复制成功切换勾选。控件统一高度、圆角和焦点环，按钮在精细指针悬停时轻微抬升，按压回落；减少动态效果时取消位移。输入框与下拉框在收缩时允许缩小，长选项保留原生菜单完整内容。

下载状态使用公共状态卡：阶段、文件详情、指标、进度条分别展示，宽屏指标靠右，窄屏自然换行。下载百分比对应真实字节，打包与未知大小使用不定进度；停止和失败隐藏进度条，保存交接成功使用成功色。文件名保持单行与可读字号，宽度不超过可用空间及 72ch，超出使用省略号，悬停显示完整文件名。错误信息允许换行以保留诊断内容。

## 滚动条

全站页面、输入框、候选列表与命令块统一使用 `src/client/styles/scrollbars.css`：炭灰轨道、灰银滑块，Chromium / WebKit 使用 10px 轨道和圆角滑块，悬停提亮、拖动使用品牌蓝；其他引擎使用标准 `scrollbar-width` / `scrollbar-color`。粗指针设备保留较宽操作区域，强制颜色模式使用系统色，不隐藏滚动条、不模拟滚动物理效果、不引入持续动画。保留原生滚轮、触摸与键盘操作；候选列表可通过 Tab 聚焦并以键盘滚动，焦点沿用品牌色描边。系统是否自动隐藏滚动条仍由浏览器与操作系统决定。新增可滚动区域直接复用该公共入口，颜色和尺寸通过共享变量维护。

参考 [Radix Scroll Area](https://www.radix-ui.com/primitives/docs/components/scroll-area) 的细窄圆角外观与原生滚动交互，以及 [SimpleBar](https://github.com/Grsmto/simplebar) 保留原生滚动的方案；项目为原生 JavaScript 页面，使用自有 CSS，不复制组件源码或添加 React / SimpleBar 依赖。兼容策略参考 [Chrome 滚动条样式说明](https://developer.chrome.com/docs/css-ui/scrollbar-styling)，稳定槽位参考 [MDN scrollbar-gutter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scrollbar-gutter)。

## 下载页布局

单个 / 批量切换使用标题区的紧凑分段按钮。批量模式按配置输入、候选镜像、下载队列组织内容；具体断点与重排方式统一遵循[响应式布局标准](#响应式布局标准)。

帮助与 Compose 错误放在双栏上方；输入区右上提供文件入口，支持拖入 YAML 和编辑后自动解析。候选镜像提供逐项加入 / 移除队列的切换，每个镜像始终独占一行，镜像名及可选平台保持单行，过长省略；已入队仅以品牌色小勾标记，不重复文字徽标。容器不超过 1039px 时，候选操作缩为 36px 的加号 / 减号按钮，保留完整 title 与无障碍名称，为镜像名让出宽度；运行或排队时禁止移除。队列内移除后，焦点保留在相邻可用的队列移除按钮，队列为空时落在队列标题；使用 preventScroll，避免跳回上方候选列表或配置输入框。任务进度及下载、停止、重试集中在队列。队列右上角提供分享入口，窄屏显示带完整提示的分享图标；并发和独立 TAR 提示位于标题下方。队列表头的架构选择以未选择占位文案呈现，支持统一设置与单项覆盖；不展示服务名。操作列使用居中的双文字按钮，蓝色强调主操作，停止与移除悬停使用危险色；运行或排队时禁用移除。提示区使用统一炭灰表面，帮助为紧凑折叠标题，Compose 问题以低对比背景和左侧危险色线条区分，避免整块高亮红框。复制按钮复用公共图标及成功反馈。

批量任务采用无内层边框的紧凑进度与较细进度条，下载指标将真实百分比放在最前，随后为已下载大小 / 总容量和速度。完成指标与「已保存 · 文件名」在同一预留行交替淡入淡出，所有完成项使用同一文档动画时间轴同步切换，避免切换造成行高变化；文件名可省略并通过悬停查看全文。减少动态效果时两组信息静态分行显示，并隐藏完成进度条，维持两行上限。

新增任务以短暂向下位移入场，不等待动画才启用操作；减少动态效果时直接显示。
