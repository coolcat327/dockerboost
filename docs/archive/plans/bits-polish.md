# Bits 视觉细节增强

状态：已实现（2026-10-15）。

目标：在现有炭灰主题中加强蓝银边缘光与操作反馈，不改变布局或任务逻辑。

- 根据 MCP 的 `@react-bits/BorderGlow-JS-CSS` 示例借鉴分层边缘光思路，用现有指针坐标驱动 CSS 局部描边，不复制组件或增加 React 依赖。
- 按钮仅在可用的悬停或键盘聚焦时扫光。
- 装饰不参与点击；减少动态效果关闭扫光，触屏无需悬停即可操作。
