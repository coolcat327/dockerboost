# 转换与命令手册

目标：新增转换、手册两个标签，保留原有四页和下载生命周期。转换在浏览器本地使用 Composerize / Decomposerize；不上传或执行输入。手册提供 Docker / Docker Compose 常用命令、参数、示例的中英文搜索及官方完整参考入口。

结构：`features/convert/` 管理双向转换与校验，`features/manual/` 管理独立内容目录、搜索和文档详情；在现有 feature 注册表与 HTML 接入，复用语言、复制、表面和按钮。无服务端 API 变化。转换依赖延迟加载，构建支持版本化代码分块，避免其他标签加载转换库。

实现：先核查库的浏览器兼容性与边界，再接入页面；编辑后清除旧结果，错误不保留可复制输出；明确复杂编排无法保证无损转换。手册内容独立编写，以官方 CLI 文档核对，完整参数通过官方链接查询。

响应式：导航保持单行局部滚动；转换在容器 760px 起双栏，窄屏上下排列；手册在容器 760px 起列表/详情双栏，窄屏纵向排列并限制列表高度。长命令在局部滚动，所有输入和操作支持触屏与键盘。

验证：转换真实示例、双向核心字段、错误与复杂编排；手册两类搜索及无结果；运行 check、相关测试、build 和完整回归。浏览器检查中英文 320/390/768/1100/1280 视口及 759/760/761 容器、方向键、减少动态效果和长文本。记录实际验证，真机验收单列为未执行。

## 交付与验证

已实现：六标签注册、双向本地转换、50 条常用命令（31 条 Docker、19 条 Compose）的中英文搜索、参数与示例详情、官方完整索引与参考链接。复用现有控件与表面，没有新增组件框架。转换库按需加载；页面分块与下载经典 Worker 分别构建，保持版本化资源与下载入口兼容。

转换额外保留命令数组边界，处理引号、空格、美元符号与生成命令的 Shell 转义，移除上游无效项目名占位符。无效输入阻止输出；编辑和方向变化清空旧结果；组件加载失败提示刷新；依赖等待、运行方式、外部资源及忽略参数显示提示。上游库不保证全字段无损互转，页面和现行文档均保留该限制。新增第三方许可文本随版本资源分发；core-js 的提示安装脚本显式禁用，锁定依赖安装通过。

实际验证：

- `pnpm install --frozen-lockfile` 成功，Node.js 26.12.0 / pnpm 12.14.0。
- `pnpm run validate` 通过：check、198 项回归、生产构建。
- 补充复制状态与布局细节后重新执行 `pnpm run check`；最后补充多行忽略参数注释后，运行转换 / 手册 / 构建相关测试（最终 15 项全部通过；构建测试重新生成生产资源）。`git diff --check` 通过。
- 本机 Chrome 无头浏览器共 39 组检查，无未捕获脚本错误。覆盖首次转换才加载引擎、双向示例与复制、无效输入与旧结果失效、加载失败、加载期间编辑的竞态、范围与关键词搜索、零结果、示例复制、方向键 / Home / End 和 390px 触屏模拟。
- 中文 / 英文分别检查 320、390、768、1100、1280px 视口；检查内容容器 539/540/541 和 759/760/761px。新页面无整体横向溢出，单双栏切换符合断点；长命令局部滚动。检查减少动态效果，缩放及语言切换后保持活动标签可见。
