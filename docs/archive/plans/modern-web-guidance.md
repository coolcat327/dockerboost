# Modern Web Guidance 前端调整

## 目标与范围

按适用于当前原生页面的指南审查语义、可访问性、表单、标签、复制、进度、字体、布局、动效、颜色、性能及浏览器安全。保留品牌深色主题、标签首次激活初始化、镜像共享状态、Registry 透传及下载任务生命周期；不为了指南中的可选示例新增菜单、弹窗、浅色主题或其他产品能力。

## 结构与实施

- `src/client/index.html`、`common/language.js` 与各功能模板：连续标题层级、初始隐藏状态、可访问名称与文案同步。
- `app.js`：沿用统一标签和复制入口，改善面板隐藏语义、重复提示与复制目标描述，不另建功能生命周期。
- `styles/` 与功能 CSS：字体相对单位、文本放大、触屏目标、焦点、颜色对比度、强制颜色及减少动态效果；沿用容器断点。
- `common/download-progress.js` 与下载样式：保留真实进度和重试逻辑，完成信息静态可读，去掉持续轮播。
- 字体与构建：优先压缩现有本地字体并保留许可证，检查版本化路径、资源请求预算和懒加载边界。
- 安全：检查 DOM 数据来源和现有跨域契约；不盲目启用可能阻断 Registry 或下载的隔离策略。只在验证影响后调整低风险页面头。

## 验证安排

先运行相关逻辑和构建测试，再运行类型、边界及全量回归。浏览器核对中英文、六个标签、宽窄屏、键盘、减少动态效果、强制颜色及字体放大；布局覆盖标准视口和受影响容器断点。真实移动端键盘、物理设备、读屏软件和线上安全策略观测如未执行则明确记录。静态 legacy-scan 仅覆盖指南库约 20%，不作为全面通过的依据。

## 已实现与适用性核对（2026-11-14）

| 范围 / 指南 | 结果 |
| --- | --- |
| accessibility、html | 连续标题层级、初始隐藏面板、键盘跳转、滚动区域命名、复制用途、文档语言与可访问状态同步。 |
| forms、copy-button | 标识符输入禁用纠正，复制按钮明确 type；提示清除旧文本并区分重复播报；旧剪贴板回退恢复焦点。沿用统一 click 入口，不另增 Invoker Commands 监听以避免双次复制。 |
| tabs | 使用原生 hidden / until-found 与 beforematch；不支持时普通隐藏。保留现有跨浏览器 ARIA / 方向键实现；共享底线改用边框，选中样式由 aria-selected 驱动。 |
| typography、responsive-design、form-factor-adaptation | 字号和组件断点使用字体相对单位；标题、导航及品牌可在大字体下换行；控件最小尺寸替代固定文字高度，粗指针目标至少 44px，代码输入至少 1rem，提示避让安全区。 |
| color、css | 控件边界、错误文字、主按钮文字对比度修正，disabled 状态不再命中悬停装饰；强制颜色使用系统色、原生选择箭头和非颜色选中标记。保持现有 CSS 入口结构及品牌深色主题，不引入主题切换或全局层级重写。 |
| motion | 保留有限入场和事件驱动视差；去掉 Hero / 光幕持续循环与完成信息轮播；减少动态效果关闭空间移动，保留颜色反馈；任务不定进度放慢，不伪造完成。 |
| progress | 原生 progress 提供 value / max；未知总量不设 value，WebKit / Blink 与 Firefox 分开定制，保存与重试仍沿用原生命周期。 |
| performance | 本地字体无损转为 WOFF2：264804 → 95184 字节（约减少 64%），只预加载首屏 Manrope；保留图片尺寸、首屏优先级、重型转换引擎和 Worker 的既有加载边界。CSS import 在构建时合并，不产生浏览器请求瀑布；没有为小型页面添加 content-visibility 或新 Service Worker。 |
| adapt-scrollbar-to-contrast-preferences | 标准滚动条优先，仅在缺少 scrollbar-color 时使用旧 WebKit 选择器；高对比度提高明暗差异，不动画滚动条颜色。 |
| security | 检查动态 DOM 数据来源与 Worker 通信；外部数据没有写入 HTML sink。两平台静态页面头一致加入 nosniff、Referrer / Permissions Policy、object / base 限制和同源嵌入限制。严格脚本 CSP、Trusted Types、报告收集及隔离策略不盲目启用，边界已归属部署文档。 |

无登录、密码、支付、第三方嵌入、日历、Canvas、Web Components 或需要 SharedArrayBuffer 的工作流，对应指南不适用；不为了扩大指南覆盖新增产品能力。当前项目的受控富文本常量与静态模板保留，不把它们误判为未清洗用户 HTML。现有下载缓存、失败重试、OPFS 和服务端流式响应未改变。
