# 固定脚本与参数统一

状态：已实现。原计划记录于 2026-10-24；本次终端下载迁移及文档整理于 2026-10-27。

## 范围与结果

单个和批量镜像终端下载共用静态 `public/download-images.sh`，页面传入站点和每组镜像、平台及镜像源；脚本通过新增 `/api/download-plan` 获取数据，复用 Registry 流式透传。批量任务最多并发处理 5 个镜像，每个镜像最多并发下载 4 个 blob，单个 blob 失败时最多重试三次并采用 1、2、4 秒退避。离线安装包的终端下载使用静态 `public/download-docker.sh`，通过既有安装计划和资源接口获取包内容。

旧 `/api/download-script` 和 `/api/install/script` 保留兼容。离线包内安装与卸载脚本仍由安装计划生成；配置页的配置命令不属于此次下载脚本迁移。浏览器下载任务及缓存生命周期未另建。当前参数、依赖、接口及行为以 [下载机制](../../downloads.md) 和 [接口参考](../../api.md) 为准。
