# 统一下载信息与进度

2026-10-22 已实现，延续工具区视觉优化。

## 目标与对接

镜像下载与离线安装包此前各自维护状态、速度、百分比和进度条 CSS。下载字节映射到 90%、打包固定 95%，文字和条形进度不一致；镜像状态可能缩小至 8px，完成与错误状态的展示、语言切换也不同。

新增 `src/client/common/download-progress.js`，负责两处实际共用的展示状态与格式化，复用 `transfer-progress.js` 的速率和大小工具。新增 `src/client/styles/download-progress.css`，通过原有样式入口加载；删除两处专属进度布局。HTML 保留原 ID 并加入统一布局类、独立文件详情和指标节点。

安装与镜像功能把原有任务事件送入公共展示模块。真实字节进度与解析、打包、保存交接阶段分开；保存交接完成后显示归档大小与总耗时。停止、失败、重试、版本或镜像选择重置使用统一清理规则。状态和耗时支持中英文，原始异常诊断不改写。

镜像下载在启动时捕获选中的镜像和平台，避免准备任务期间表单变化改变本次下载目标；保存前再次检查取消信号。API、Worker 消息契约、归档格式、缓存及公共任务生命周期保持兼容，无新增依赖。

长期说明见 [下载机制](../../downloads.md#下载状态与进度展示) 和 [视觉规范](../../ui.md)。

## 后续冗余清理
