# 计划管理与待办

本目录维护待执行或仍在验收的工作范围与实施方案，以及计划状态的流转规则；不作为当前实现规范。完成记录只在历史归档维护索引。

## 状态与归档

- 本目录中的待执行计划：待实现或仍在验收的方案。按任务需要创建目录与文件，不为空目录添加占位文档。
- `../archive/plans/`：已经实现的交付记录。记录当时实际验证和未执行项目；标记已实现不代表所有真机、性能或线上检查均已完成。
- 每份计划只保留一个位置。完成实施及约定验收后移动到 `../archive/plans/`，未完成事项在记录中明确说明；需要后续推进时另建范围独立的待办计划。
- 归档前将已生效的规则更新到所属现行文档，计划中只保留本次工作的范围、决策、迁移和验证记录。历史命令、依赖版本和测试数量不改写为当前值。

## 方案内容

涉及多阶段实施、选型取舍或后续工作的任务，计划至少包括：

- 目标、范围、不变的功能契约和风险。
- 新增、修改和复用模块的路径、职责与依赖方向。
- 接口与数据契约、调用链和生命周期变更。
- 与现有实现的对接、兼容方式及实施顺序。
- 验收标准、验证方法，以及交付时实际执行与未执行的项目。

小幅修正无需单独建立计划。
