## 目标与范围

保留蓝色品牌、冲浪插画及安装、配置、拉取、下载四标签顺序，统一炭灰表面、低频灰银光幕与稳定暗色工具区。基于已有未提交实现继续完善，不改变 Worker 或下载生命周期。

## 当前实现

- `foundation.css` 统一配色、字体、焦点和减少动态效果；`atmosphere.css` 提供单一背景、静态颗粒与低频流幕。
- Hero 保留插画归位、轻浮动与桌面视差；交互可中断入场。标签共用活动线及短暂内容过渡。
- `page-motion.js` 按帧合并指针更新，隐藏页面或 Hero 离屏暂停背景；工具区保持独立可操作。
- 本轮根据 React Bits SpotlightCard MCP 示例，补充工具区静态键盘聚焦柔光和边界、公共光色变量，修正禁用主要按钮的悬停底色。
- 文档合并为设计规范与计划，计划按待实现、已实现分目录；设计和实现采用同一验收流程。
