# 工具区视觉与响应式控件优化

2026-10-22 已实现。

## 范围与实现

保留炭灰表面、品牌蓝、Hero 和四标签顺序。解决固定宽度操作组挤压输入区、窄屏按钮与字段脱节，以及主次操作缺少区分的问题。

- `src/client/styles/workspace.css`：复用公共控件，增加工具面板容器查询；字段按面板宽度重排，操作组在窄屏填满、宽屏靠右。标签改为分段式表面，命令标题允许换行。
- `src/client/index.html`：只为分享与刷新增加次按钮样式类，保留原有元素、ID 与事件入口。
- `src/client/features/install/install.css`：离线安装表单沿用公共字段与按钮，根据同一面板容器重排。
- 下载、分享、刷新、复制的图标用 CSS 遮罩绘制；沿用已有停止和复制成功类更新图标。原有语言更新覆盖文字时不会移除图标。
- 动画使用原有单次扫光、焦点与面板入场，增加短暂悬停抬升与按压回落。减少动态效果关闭位移与过渡。

没有接口、数据契约、共享状态或下载生命周期变化，没有新增运行时依赖。StarBorder 候选组件的依赖和取舍见 [选型记录](../../research/react-bits.md)。长期规则更新至 [视觉规范](../../design/visual-style.md) 和 [前端开发](../../development/frontend.md)。

## 中间宽度布局修正

后续截图反馈确认：面板 780–1040px 时三个字段同排、操作组被强制放到下一行，虽然没有溢出，仍造成按钮与字段脱节。删除这个过渡布局；拉取和下载保持两列，架构与操作区同行，空间足够才切换为整行。安装页的换行操作组填满两列，与上方字段对齐。页脚删除 `PUBLIC IMAGES ONLY ·` 节点和 `.footer-scope` 隐藏规则，右侧仅保留 STATUS 链接。

针对性浏览器检查在 1160px 修正前测得字段与按钮底部差 72px，修正后差 0px。中英文、安装/拉取/下载三个标签及 17 种视口宽度（320–1440px）共 102 组检查通过，检查字段/按钮横向溢出、中间布局底部对齐及页脚文字移除，并查看 1160px 截图。生产构建和 `git diff --check` 通过。本次仅模板与样式调整，未重跑完整代码测试，未做真机验证。
