DOCKER INSTALLATION

在线安装与离线包

在线安装

在线安装脚本来自 LinuxMirrors，提供 Docker 安装与换源的交互引导。在联网 Linux 主机上以 root 运行，按提示选择版本和镜像源；需要 Bash 和 curl。

LinuxMirrors
bash <(curl -sSL __CONFIG_onlineInstallScript__)

离线安装

适用于全新安装的 systemd Linux。包含安装说明、Docker 静态包、Compose、daemon.json、服务文件、校验文件及交互安装脚本。

离线安装包
下载离线安装包
选择版本后自动显示下载命令

在联网 Linux 机器下载，完成后将 tar 包复制到离线机器。解压：tar -xf docker-offline-*.tar，再执行 sudo sh offline_install_docker.sh。交互询问数据目录、镜像源、日志大小/数量及 live-restore，回车使用默认值。
